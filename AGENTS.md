# AGENTS.md

Инструкции для AI-агентов в репозитории aiproxy — мульти-провайдерный AI API прокси, форк copilot2api v0.4.0.

## Идентификация проекта

- **База:** [copilot2api v0.4.0](https://github.com/whtsky/copilot2api). Это форк. За документацией к базовому проекту — в оригинальный репозиторий.
- **Модуль:** `github.com/whtsky/copilot2api`
- **Рантайм:** Docker Compose — сервис `aiproxy`, контейнер `aiproxy`, образ `aiproxy:local`, порт `127.0.0.1:8081` → `7777`.
- **Роутинг моделей:** по префиксу. `copilot-gpt-5.4` → Copilot, `deepseek-v4-pro` → DeepSeek, и т.д.

## Документация

- `README.md` — руководство пользователя: установка, конфигурация, эндпоинты, клиенты
- `ARCHITECTURE.md` — структура пакетов, поток запроса, логика роутинга, инварианты
- `docs/claude-cli.md` — провайдер Claude по подписке через официальный CLI
- `docs/authorization.md` — три механизма авторизации (Copilot, OpenAI, Claude, api_key)
- `CHANGELOG.md` — изменения по версиям
- `CLAUDE.md` — симлинк на этот файл

## Правила

- При изменении поведения, API, роутинга или user-visible настроек обновляй `CHANGELOG.md` в том же изменении — в секции `## [Unreleased]` (создай её над последней версией, если её нет).
- Записи в changelog: короткие сгруппированные пункты под заголовками `Новые возможности`, `Исправления`, `Изменения поведения` и т.д.
- Не включай внутренние рефакторинги, тесты или CI-изменения, если они не затрагивают пользователей.
- Не удаляй старые заметки о релизах без явного запроса.
- Все настройки провайдеров — через `providers.json`. Никаких env-переменных для отдельных провайдеров.
- `proxy_host` провайдера использует `upstream.ParseProxyURL` — поддерживает `http://`, `https://`, `socks5://`, `socks5h://`. Глобальной переменной `PROXY` нет; заданный прокси не имеет fallback на прямое соединение.
- Аутентификация провайдера: `oauth` (device flow для Copilot и OpenAI; нативный вход Claude Code для `claude-cli`) или `api_key` (статический ключ в json). Взаимоисключающие — проверяется при старте. Токены Copilot/OpenAI — в `COPILOT2API_TOKEN_DIR`, креды `claude-cli` держит сам CLI и aiproxy их не читает.
- `providers.json` обязателен. Никакого устаревшего env-var fallback.

## Верификация

- `go build ./... && go vet ./... && go test ./...` — полный цикл сборки и тестов
- `docker compose build` — Docker-образ `aiproxy:local`
